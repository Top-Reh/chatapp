# 🔥 Chatapp

A real-time chat application built with **React** and **Firebase**. Users can sign up, log in, search for other users, and exchange messages instantly — all with a sleek, responsive interface.

📍 [Live Demo](https://top-reh.github.io/Chatapp/)

---

## 🚀 Features

- 🔐 **Authentication** (Sign Up / Login) via Firebase Auth
- 👥 **User Search** by username
- 💬 **Real-time Messaging** with Firestore
- 📁 **User Chats** management
- 🔄 **Auto Scroll** to latest message
- 📱 **Responsive** design

---

## 🛠️ Tech Stack

- **Frontend**: React, CSS
- **Backend**: Firebase (Authentication + Firestore)
- **Deployment**: GitHub Pages
